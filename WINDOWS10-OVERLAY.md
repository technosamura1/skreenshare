# Windows 10: указка, стикеры и рамка захвата

## Изменения

- Для трансляции целого монитора на Windows 10 до build 20348 выбирается Desktop Duplication: он не создаёт жёлтую рамку WGC. На Windows 11 выбор WGC сохранён. SS_CAPTURE=wgc/dd остаётся диагностическим переопределением.
- Оверлей получает два разных исключения: WDA_EXCLUDEFROMCAPTURE для WGC и WCA_EXCLUDED_FROM_DDA=24 для Desktop Duplication. Второе задаётся и проверяется через динамически найденные функции user32.dll. WDA само по себе больше не считается достаточным для DDA.
- Перед сменой захвата поток оверлея подтверждает скрытие окна. Показ разрешается только по подтверждённому исключению соответствующего backend. Это устраняет прежнее безусловное скрытие оверлея при переходе на DDA.
- connect.log различает приём первого пакета, настройку показа и проверку исключения каждого backend.

## Проверки

- Windows 11 Pro build 26300: 265 тестов прошли, 3 ignored; Release собран.
- Отдельный локальный тест dda_excludes_test_overlay создал белое фоновое окно и чёрное layered-окно. До исключения DDA получил [0,0,0], после — фон [254,254,254]. Проверено отсутствие чёрной области и попадания тестового оверлея в кадр. Изображения рабочего стола не сохранялись, сетевых запросов не было.
- Проверки выбора backend для Windows 10 19045 и Windows 11 22000, независимых флагов исключения и отказа при отсутствии подтверждения.

## Ограничения

На физическом Windows 10 друга код не проверялся; точная причина односторонней невидимости без его журнала остаётся предположением. Если исключение не подтверждается драйвером/Windows, оверлей по-прежнему безопасно скрывается; причина записывается в connect.log. Настройка show_pointer=0 также отключает показ.

Для отдельного окна сохранён WGC. На Windows 10 22H2 системную рамку через этот API отключить нельзя: свойство IsBorderRequired появилось с build 20348. Подмена захвата окна обрезкой всего монитора не сделана, поскольку перекрывшие его чужие окна тогда могли бы попасть в трансляцию.
