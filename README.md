# screenshare

Показ экрана со звуком другу через интернет напрямую, без серверов и регистрации.
Видео — HEVC через NVENC (нужна видеокарта NVIDIA у того, кто показывает), 60 кадров/с, ~40 Мбит/с.

## Как пользоваться

1. Запусти `screenshare.exe` — это один файл, ничего распаковывать не нужно. Если Windows спросит про доступ
   к сети — разреши. (При первом запуске программа за секунду-две сама разложит FFmpeg в
   `%LOCALAPPDATA%\screenshare`.)
2. Кто показывает — **«Показать мой экран»** → «Начать». Появится код `H...` — «Скопировать код» и отправь другу.
3. Кто смотрит — **«Смотреть экран друга»**, вставляет код `H...` → «Подключиться». Появится код ответа `C...` — отправь его обратно.
4. Показывающий вставляет код `C...` → «Подключить». У друга на весь экран откроется твой экран.
   **F11** или **двойной клик** — переключить полный экран / окно, **Esc** — выйти из полного экрана.

**«Проверить на этом ПК»** — трансляция и просмотр у себя же: увидишь ровно то, что увидит друг.

Коды одноразовые: на каждый запуск — новые.

## Звук и Discord

Передаётся весь звук компьютера **кроме Discord** (и Discord PTB/Canary, Vesktop) — поэтому друг не слышит
сам себя эхом, даже если вы сидите в голосовом канале. Если Discord запустить или перезапустить во время
трансляции — программа сама это заметит за пару секунд. Если Windows слишком старая и не умеет исключать
программы из захвата, а Discord запущен — звук не передаётся вообще (лучше тишина, чем эхо).
Проверить на своём ПК: `screenshare audiotest`.

Discord в браузере исключить нельзя (пришлось бы глушить весь браузер) — пользуйтесь приложением Discord.

## Если не подключается

- Оба должны вставить коды из *этого* запуска (не старые).
- Если программа пишет про «симметричный NAT» — у этого провайдера прямое соединение может не работать
  (чаще всего мобильный интернет). Попробуйте поменяться ролями или другую сеть.
- Проверь, что файрвол Windows не блокирует `screenshare.exe`.

## Параметры для продвинутых

```
screenshare host --bitrate 60 --monitor 1     битрейт в Мбит/с, номер монитора
screenshare monitors                          список мониторов
screenshare selftest                          проверка кодирования на этом ПК
screenshare --help                            всё остальное
```

## Сборка

Нужны Rust, Visual Studio Build Tools (C++), LLVM, и FFmpeg shared-сборка
(BtbN `ffmpeg-n8.1-latest-win64-gpl-shared-8.1.zip`) распакованная в `third_party/ffmpeg`.
У BtbN библиотеки импорта в формате GNU — один раз пересоздай их в формате MSVC (нужно для /DELAYLOAD):

```
powershell -ExecutionPolicy Bypass -File tools\make-import-libs.ps1
cargo build --release
```

DLL FFmpeg встраиваются в exe (build.rs, zstd), грузятся отложенно и распаковываются при первом запуске
(src/bundle.rs) — на выходе один `target\release\screenshare.exe`.
