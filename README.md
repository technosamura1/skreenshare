# Skreenshare проектор

Показывает экран и звук Windows-компьютера на Android-проекторе (например TouYinGer H6) по домашнему Wi-Fi.
Без кодов, без интернета, без аккаунтов. Видео кодирует видеокарта NVIDIA (NVENC, H.264), задержка обычно 100–200 мс.

Состоит из двух программ:

| Файл | Куда ставить |
|---|---|
| `skreenshare-proektor.exe` | на компьютер с Windows 10/11 и видеокартой NVIDIA (GTX 900-й серии и новее) |
| `skreenshare-proektor.apk` | на проектор (Android 5.0+) |

Проект сделан на основе приватного репозитория `technosamura1/screenshare` (Rust, захват экрана DXGI, WASAPI loopback, NVENC);
ручные коды и обход NAT убраны, вместо них — автопоиск в локальной сети и свой UDP-протокол.

## Установка на проектор
1. Скачайте `skreenshare-proektor.apk` (GitHub → Releases) на компьютер.
2. Любой из способов:
   - **Флешка**: скопируйте apk на флешку, вставьте в проектор, откройте файловый менеджер проектора и запустите файл;
   - **Ссылка**: загрузите apk в облако (Google Диск / Яндекс Диск), откройте ссылку в браузере проектора и скачайте файл;
   - **По USB-отладке (adb)**: `adb connect IP_проектора` → `adb install skreenshare-proektor.apk`.
3. Если проектор ругается на «неизвестные источники» — разрешите установку из этого источника (Настройки → Безопасность).
4. Запустите «Skreenshare проектор». Приложение покажет «Ожидание компьютера...» и своё имя и IP. Экран проектора не будет гаснуть.
   Выход — кнопка «Назад» на пульте.

## Использование
1. Проектор и компьютер должны быть в **одной сети Wi-Fi** (или компьютер по кабелю в тот же роутер).
2. На проекторе откройте приложение.
3. На компьютере запустите `skreenshare-proektor.exe` (установка не нужна). При первом запуске Windows спросит про доступ к сети — **нажмите «Разрешить»**
   (иначе проектор не найдётся). Первый запуск занимает пару секунд — программа распаковывает свои компоненты в `%LOCALAPPDATA%\skreenshare-proektor`.
4. Проектор появится в списке. Если он один — он выбран сам. Нажмите **«Транслировать»**. Остановить — кнопка «Остановить».
5. Качество: по умолчанию Full HD 30 к/с (10 Мбит/с). Если картинка рвётся или лагает — выберите «HD 720p». Если Wi-Fi хороший и проектор тянет — «Full HD 60 к/с».

### Если проектор не находится
- Откройте на проекторе приложение и убедитесь, что в нём написан IP-адрес (вида 192.168.x.x).
- Нажмите в программе на ПК «Не находит проектор? Ввести IP вручную» и введите этот IP.
- В роутере выключите «изоляцию клиентов» / «AP isolation» (из-за неё устройства в Wi-Fi не видят друг друга). Гостевая сеть часто так и работает.
- Проверьте брандмауэр Windows: Параметры → Брандмауэр → «Разрешить работу с приложением» → отметьте `skreenshare-proektor.exe` для частных и общедоступных сетей.
- Порты: UDP 47800 (проектор) и 47801 (компьютер).

### Если лагает или звук хрипит
Wi-Fi 5 ГГц намного лучше 2,4 ГГц; компьютер лучше подключить кабелем. Снизьте качество до 720p.

## Ограничения (v0.1)
- Только Windows + NVIDIA. Нужен свежий драйвер (для NVENC).
- Трафик в сети не шифруется и не защищён PIN: любой в вашей сети может попробовать подключиться к проектору. Для домашней сети нормально.
- Один компьютер за раз; новый запуск перехватывает проектор.
- Звук: это звук, который играет на колонках ПК (WASAPI loopback), он продолжает звучать и на ПК — убавьте/выключите колонки ПК. Если на ПК ничего не играет, звук тишиной не идёт.
- Звук и картинка синхронизируются «на глаз» (без точной A/V-синхронизации); на слабых проекторах возможен небольшой рассинхрон.
- Курсор мыши рисуется программно; защищённое DRM-видео (Netflix в браузере) может быть чёрным.
- Приложение подписано одним общим ключом из репозитория (`android/release.keystore`) — это не секрет, обновления ставятся поверх.
- Реально проверялись: сборка, протокол (тесты на Rust и Kotlin с одинаковыми эталонными байтами), разбор/патч H.264. Работа на живом железе (NVENC, Wi-Fi, ваш проектор) в первой версии не тестировалась — присылайте, что увидите.

## Сборка
- **Android**: `cd android && ./gradlew assembleRelease` (JDK 17+, Android SDK 34) → `android/app/build/outputs/apk/release/app-release.apk`.
- **Windows exe на Linux**: `tools/build-windows-on-linux.sh` (cargo-xwin, clang/lld; скачивает FFmpeg LGPL shared от BtbN, делает MSVC import-библиотеки через `llvm-dlltool`).
- **Windows exe на Windows**: Rust + Visual Studio Build Tools + LLVM; распакуйте FFmpeg (`ffmpeg-n9.0-latest-win64-lgpl-shared-9.0.zip`) в `third_party/ffmpeg`,
  выполните `tools/make-import-libs.ps1`, затем `cargo build --release`. FFmpeg DLL упаковываются внутрь exe, поэтому exe один файл (~45 МБ).
- **CI**: заготовка `ci/build.yml` (не проверена). Чтобы включить GitHub Actions, скопируйте её в `.github/workflows/` — для пуша в эту папку токену нужен scope `workflow` (`gh auth refresh -s workflow`).
- Тесты: `cargo test -p proto` и `cd android && ./gradlew testDebugUnitTest`.
