# skreenshare

Трансляция экрана Windows со звуком — другому человеку, через интернет, напрямую.

Своего сервера нет, аккаунт не нужен. Картинка идёт от компьютера к компьютеру. Один файл `screenshare.exe`: скачал, запустил, отдал код.

**[Скачать 0.12.8](https://github.com/technosamura1/skreenshare/releases/tag/screenshare-v0.12.8)** — `screenshare-0.12.8.exe` и рядом файл `.sha256`, чтобы сверить, что exe не побился по дороге.

## Для чего

Показать рабочий стол, игру или одно окно человеку, который сидит не рядом.

- коллеге — документ, ошибку, то, что на экране;
- другу — игру или рабочий стол;
- себе — со своего компьютера на другой.

Зритель может только смотреть. Управление мышью, клавиатурой и геймпадом включается отдельно и только если показывающий разрешил.

## Как подключиться

1. Оба запускают один и тот же exe. Если Windows спросит про сеть — разрешить.
2. Кто показывает, нажимает «Показать экран» и выбирает весь экран, монитор или одно окно.
3. Кто смотрит, подключается одним из способов ниже.

Дальше у зрителя открывается картинка. **F11** или двойной щелчок — полный экран, **Esc** — выйти из него.

### Короткий код

Показывающий включает «Простое подключение» и получает код вроде `K7QM-X2PD`. Зритель вставляет его в «Смотреть». Ответ уходит сам, второй код диктовать не нужно.

Код живёт около 15 минут. Через него передаётся только зашифрованное приглашение (ChaCha20-Poly1305) на публичный ntfy-me.com. Сервер видит случайное имя и шифртекст, не экран. Сама трансляция после этого идёт напрямую. Между друзьями картинка и звук ещё и шифруются (ChaCha20-Poly1305): кто перехватит пакеты, не посмотрит трансляцию. Старая версия у зрителя остаётся без шифра, соединение не ломается.

Если короткий код не дошёл, остаётся обычный обмен: длинный код `H…` зрителю и код ответа `C…` обратно.

### Друзья

Один раз обменялись кодом друга (или ссылкой `screenshare://friend/…`). Оба появляются в списке. Дальше показывающий жмёт «Пригласить на трансляцию», у второго всплывает «Смотреть / Отклонить».

Список хранится только на этом компьютере, рядом с настройками. Друга можно переименовать и удалить. «В сети» обновляется редко, чтобы не упираться в лимит релей.

Два профиля на одном ПК: перед запуском задайте другую папку, `SCREENSHARE_PROFILE`.

## Что умеет

- Весь экран, отдельный монитор или одно окно. Остальные окна, стол и уведомления в трансляцию одного окна не попадают.
- Звук компьютера. Голосовой чат вроде Discord по умолчанию в трансляцию не берётся.
- Видеокарта NVIDIA кодирует HEVC (драйвер 471.41 или новее). Если её нет или драйвер старый — кодирует процессор, H.264.
- Качество: «Авто», «Стандарт» (30 Мбит/с) и «Высокое» (60 Мбит/с). При потерях битрейт снижается сам.
- HDR на мониторе показывающего приводится к обычной картинке, чтобы у зрителя не выжигало белым.
- Удалённое управление — по галочке. Аварийно снять его у себя: Ctrl+Alt+Shift+F12.
- «Проверить на этом ПК» показывает ровно то, что уйдёт зрителю.

Настройки лежат в `%LOCALAPPDATA%\screenshare`. При первом запуске программа сама раскладывает туда FFmpeg.

## Что нужно

Windows 10 или 11, на обоих компьютерах. Устанавливать ничего не надо.

NVIDIA желательна у того, кто показывает, но не обязательна. Зрителю отдельная видеокарта не нужна: если аппаратный декодер не найдётся, декодирует процессор.

Интернет нужен, чтобы найти друг друга. Дальше трафик идёт между вами, не через сервер программы.

## Собрать самому

Нужен Rust и Windows.

```
cargo build --release
cargo test --release
```

Готовый файл: `target\release\screenshare.exe`.


### Бесплатный сервер приглашений

Новая UI-сборка использует ntfy-me.com (бесплатный публичный сервис). Обновиться нужно обоим друзьям: старая сборка остаётся на ntfy.sh. Список друзей и ключи сохраняются; старые приглашения между серверами не переносятся. Переменная SCREENSHARE_RELAY по-прежнему задаёт другой совместимый сервер, одинаковый у обеих сторон.

Фоновые heartbeat отправляются существенно реже: при одном друге примерно раз в три минуты; общий расчётный бюджет — до 480 heartbeat в сутки на непрерывно работающий экземпляр плюс сообщения при запуске/добавлении друзей. Приглашения и запросы отправляются сразу, получение зависит от цикла опроса. Индикатор «в сети» приблизительный: после закрытия приложения может сохраняться несколько минут, а при большом списке дольше. Публичный сервис имеет собственные квоты и не гарантирует доставку; лимит не обходится, после 429 действует пауза.

Видео и звук по-прежнему передаются напрямую; сервер получает только зашифрованные служебные сообщения и сетевые метаданные. Условия сервиса: https://ntfy-me.com/docs/support
