# Профили и новый дизайн

- Графитовые поверхности и плоские основные кнопки, компактный список с аватарками, поиском и фильтром доступности. Светлая/тёмная/монохромная темы, все акценты и настройки оформления сохранены.
- Профиль внизу боковой панели: имя, кот или фото PNG/JPEG, статус до 64 символов. Фото обрезается по центру и превращается в небольшую JPEG-копию; оригинал и его EXIF не передаются.
- Профиль друга открывается по аватарке или меню строки. Локальное переименование друга не перезаписывает его настоящий профиль.
- Обновление идёт отдельным зашифрованным сообщением по существующему каналу пары. Обычный presence сохранён, поэтому старые версии продолжают видеть имя/доступность; для аватара и статуса обе стороны должны обновиться.
- Профиль отправляется при запуске, добавлении друга и изменении данных; неизменённые профили повторно не публикуются. Ошибка отправки не помечает профиль отправленным. Сохраняется минимальный промежуток сетевых запросов. При большом списке доставка может занимать несколько циклов опроса.
- Последние полученные профили сохраняются в profiles.txt и доступны офлайн. Ключи и идентификаторы существующего профиля не меняются. Эти данные не защищены DPAPI, как и существующий локальный профиль.
- Размер сообщения ограничен для лимита ntfy 4096 байт; фото до 1600 байт, имя до 40 символов, статус до 64. Входящие изображения декодируются с лимитом размеров 64×64; исходные локальные фото ограничены по размеру файла, пикселям и выделению памяти. Текст отображается как обычный текст.

## Проверки

- Windows: cargo test --release — 256 passed, 2 ignored; cargo build --release — успешно.
- Переносимые тесты tools/lossim — 253 passed, 1 ignored.
- Автотесты: шифрованный обмен профилем, лимит сообщения, кеш после перезапуска, сохранение локального псевдонима, отказ на чрезмерном payload и невалидной фотографии.
- tools/profile-integration.py: две реальные свёрнутые копии launcher через localhost HTTP relay; имя, статус и JPEG получены в обе стороны и сохранены. Использованы curl и production AEAD, не обход криптографии. Требуется Windows/Python/Pillow и путь к собранному EXE.
- В тестовом окне с отдельным профилем проверены экран друзей, редактор, выбор кота и сохранение с обновлением аватара в боковой панели. Финальные корректировки выравнивания скомпилированы; полный ручной прогон на разных DPI не выполнен.
- cargo audit: известных уязвимостей 0; прежнее предупреждение о неподдерживаемом ttf-parser остаётся.
- Тест реального ntfy заблокирован HTTP 429 при первом POST hello. Успешная проверка обмена профилями через публичный relay и два физических ПК не заявляется.

Версия остаётся 0.13.1. Релиз не опубликован. Часть старых локальных незакоммиченных изменений в другом worktree не затрагивалась.
