# 2560×1440, 60 FPS: захват целого монитора

Для целого монитора на Windows 10 и 11 теперь предпочитается Desktop Duplication. Если его создание не удалось, используется Windows Graphics Capture; SS_CAPTURE=wgc принудительно выбирает WGC, SS_CAPTURE=dd требует DDA без автоматического fallback. Исключение указки/стикеров из DDA проверяется отдельно, через WCA_EXCLUDED_FROM_DDA.

Разрешение, NVENC preset, настройки битрейта и алгоритмы передачи не изменены. Захват отдельного окна остаётся на WGC: результаты ниже относятся к целому монитору.

## Измерения

Windows 11 Pro build 26300, RTX 5070, локальные host/viewer на одном ПК. Передаётся и показывается 2560×1440; NVENC HEVC p4, аппаратный D3D11VA-декодер, D3D11 video processor. Включён HDR с преобразованием в SDR. Движущийся тестовый источник, без звука. Выбрано 45 Мбит/с, фактический поток простого изображения около 2 Мбит/с.

| Показатель после первых 5 секунд запуска | DDA (60 секунд) | WGC (30 секунд) |
|---|---:|---:|
| Отправлено, замеры каждые 5 секунд | 60 FPS во всех 10 замерах | 56 FPS во всех 4 замерах |
| Показано зрителю | 60 FPS во всех 10 замерах | 56 FPS во всех 4 замерах |
| Максимальный промежуток между показанными кадрами | 20 мс | 32 мс |
| Потери видео по диагностике | 0,0% | 0,0% |
| Пропуски показа из-за переполнения | 0 | 0 |

В WGC-прогоне один пакет был восстановлен повторной передачей. Первый интервал DDA: 59 FPS на отправке, 56 на показе из-за запуска. После прогрева — 60/60. FPS округляется существующей диагностикой до целого. Это не гарантия фиксированных 16,67 мс между всеми кадрами.

Отдельный native-тест DDA исключил layered-окно: до исключения пиксель был [0,0,0], после — фон [254,254,254]; чёрного пятна вместо окна нет. Полный локальный прогон: 266 passed, 3 ignored; native-тест запущен отдельно и прошёл. Запросов к публичному серверу приглашений эти проверки не делают.

## Воспроизведение

python tools/perf-smoke.py ПУТЬ_К_EXE 60 result.json screen

Для сравнения установить SS_CAPTURE=wgc перед запуском того же теста. Скрипт создаёт временный профиль, движущееся окно и два процесса с автоматическим завершением. Сохраняется только текстовая статистика, без кадров, кодов подключения и звука. Диагностический SS_PERF_EXCLUDE_VIEWER исключает fullscreen viewer из локального захвата, чтобы избежать видеопетли; в обычном приложении этот флаг выключен.

## Пределы проверки

Тест выполнен на одном ПК, не через интернет и не на GTX 1070/Intel-ноутбуке друга. Простая анимация не проверяет насыщение канала 100 Мбит/с сложным фильмом или игрой. Звук, длительная сессия и потери сети в этом измерении не проверялись. Для проверки вдвоём: целый монитор 2560×1440, 60 FPS; оценивать «показано» у зрителя вместе с потерями и максимальной паузой, а не только выбранную частоту.
